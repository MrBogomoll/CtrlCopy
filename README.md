# CtrlCopy

Небольшое приложение для Windows: выделенный текст автоматически попадает в буфер обмена. Работает в трее, без сети, телеметрии и истории буфера.

## Скачать и запустить

Скачайте `CtrlCopy.exe` или ZIP из [последнего релиза](https://github.com/MrBogomoll/CtrlCopy/releases/latest). Нужны Windows 10/11 и .NET Framework 4.8.

Сохраните приложение в постоянную папку и запустите. Значок двух листов появится рядом с часами, возможно под стрелкой скрытых значков. Правая кнопка → **Настройки**, левая кнопка включает или приостанавливает копирование. Крестик и Esc скрывают настройки; **Выход** в меню трея завершает приложение. Повторный запуск открывает настройки работающего экземпляра.

## Возможности

- Копирование выделенного мышью текста, двойного щелчка, Ctrl+A и Shift+стрелок. Unicode и переносы строк сохраняются.
- Независимые настройки копирования при выделении клавишами и автоматическом полном выделении в поле, например адресной строке. Автовыделение изначально выключено, клавиатурное выделение включено.
- Исключения: выбор файла `.exe` или одного из приложений с открытыми окнами.
- Тихий клик и небольшая контурная иконка рядом с курсором при копировании, оба эффекта можно выключить.
- Светлая и тёмная темы Windows, компактные настройки, запуск вместе с Windows для текущего пользователя без прав администратора.

Автозапуск включайте после размещения приложения в постоянной папке. При переносе выключите автозапуск в старой копии и включите в новой.

## Ограничения и данные

Приложения должны предоставлять выделение через Windows UI Automation. Нестандартные поля браузеров, игры и окна с повышенными правами могут не поддерживаться. Обычное ручное Ctrl+C остаётся доступным. Распознавания текста на изображениях нет.

Проводник, оболочка Windows и распространённые терминалы исключаются. Поля, обозначенные приложением как парольные, не копируются. Автоматическое выделение поля копируется только при подтверждении полного выделения в редактируемом поле, без отправки запасного Ctrl+C.

Настройки сохраняются в `%LOCALAPPDATA%\AutoCopy\settings.json`; прежнее имя папки сохранено для совместимости. При удалении приложения выключите автозапуск и завершите его через меню трея, затем удалите файл. Настройки можно сохранить или удалить отдельно.

## Сборка

Нужны Windows, .NET Framework 4.8 и .NET SDK. Сторонние пакеты не используются.

```powershell
.\build.ps1
.\build.ps1 -Test -Preview -PolishTest
.\build.ps1 -UiTest
.\package.ps1 -Destination .\dist
```

Сборка создаёт `bin\AutoCopy.exe`, пакет — `dist\CtrlCopy.exe`. Проверки интерфейса требуют закрытого CtrlCopy и доступного рабочего стола; временные изменения настроек восстанавливаются. `-Integration` дополнительно проверяет физическое выделение в тестовом окне и требует свободного ввода. Подробнее: [проверки](docs/verification.md).
